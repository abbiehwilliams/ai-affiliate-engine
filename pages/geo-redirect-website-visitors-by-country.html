Set Up Location-Based IP Redirection for Websites

Official Integration Guide for Geo Targetly

Directing international visitors to the correct regional website manually can cause lost sales and high bounce rates. Learn how to set up automated IP-based geographic redirection.

Table of Contents

  • Principles of IP Geolocation Routing
  • Step 1: Create Location Routing Rules
  • Step 2: Embed JavaScript Tag
  • Testing and Validation

Prerequisites and System Requirements

  • Website header code access or Google Tag Manager

Step-by-Step Implementation Procedure

1

Create Location Routing Rules

Log into Geo Targetly, select Geo Redirect, and create a new rule. Define your target country and destination URL (for example: If visitor IP is from United Kingdom, redirect to `/uk-store`).

2

Embed JavaScript Tag

Copy the lightweight code snippet generated by Geo Targetly. Paste the code into the `` section of your website HTML or publish it using your tag manager.

Best Practice: Enable 'First Visit Only' redirection so returning visitors can switch country versions manually without being forced back.
